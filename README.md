# BeBest School — новый сайт

Многостраничный сайт онлайн-школы иностранных языков BeBest с моушн-графикой.
Чистый HTML + CSS + JavaScript, без фреймворков и сборщиков — открывается в любом браузере и заливается на любой хостинг.

## Как открыть

1. Распакуйте архив.
2. Откройте `index.html` двойным кликом — сайт заработает прямо с диска.
3. Для публикации загрузите **всё содержимое папки** на хостинг (в корень домена).

> Шрифты (Unbounded + Manrope) подгружаются из Google Fonts, поэтому для «фирменного» вида нужен интернет.

## Анимации и интерактив

- Прелоадер с приветствиями на разных языках (показывается 1 раз за визит)
- Переходы между страницами «шторкой»
- Интерактивное «созвездие языков» на canvas: реагирует на курсор, по клику — ударная волна
- Кастомный курсор, магнитные кнопки, 3D-наклон карточек с бликом, подсветка за курсором
- Появление заголовков по словам, текст-«манифест» подсвечивается при прокрутке
- Счётчики цифр, бегущие строки (ускоряются от скорости скролла), параллакс
- Горизонтальный скролл «Как проходит обучение», орбита флагов языков
- Перетаскиваемый слайдер отзывов, аккордеоны, фильтры с FLIP-анимацией
- Многошаговая форма записи с конфетти
- Полная адаптация под телефоны; уважается системная настройка «уменьшить движение»

## Формы заявок

Формы не требуют сервера: после заполнения открывается WhatsApp отдела продаж (**+34 611 586 216**, как на текущем сайте) с уже готовым текстом заявки — клиенту остаётся нажать «Отправить».
Номер меняется в одном месте: `assets/js/ui.js` → константа `WA_NUMBER`.

## Как редактировать

Все страницы генерируются скриптом из папки `_build/` — так правка одного блока сразу обновляет все 87 страниц.

- Тексты, курсы, преподаватели, отзывы, FAQ, контакты → `_build/data.py`
- Программы курсов по типам → `_build/content.py`
- Шапка, подвал, форма → `_build/layout.py`
- Вёрстка страниц → `_build/pages.py`

После правок выполните:

```
python3 _build/build.py
```

Папку `_build/` загружать на хостинг не обязательно.

## Что стоит проверить владельцу

- **Юридические тексты** (`terms`, `privacy`, `cookies`, `legal`) — сокращённые редакции; вставьте полные тексты из действующих документов.
- **Фото** — вместо фотографий преподавателей и основательницы стоят стильные цветные аватары с инициалами. Реальные фото можно добавить в `assets/img/`.
- **«10 лет»** — на старой главной указано 10 лет, на странице «О нас» — 6; на новом сайте везде 10.
- **Рейтинг 4.9** в первом экране — уточните или замените актуальной цифрой.
- Статьи блога написаны заново как стартовый контент.
